## 1. 当前版本与证据口径

当前 v1.0.0 以旧版 v1.3.0 核心（原提交 844103c）为基础，保留远程设备测试台、ALSA 音量与无盲道引导页面；直接前身为本机回滚提交 89a7ecc。它不等同于旧版 v1.3.1 板端部署，也不含旧版 v1.5.0 的原生流式 ASR 与主控协议实现。

| 证据类别 | 可以支持的结论 | 不能支持的结论 |
|---|---|---|
| 当前代码的 Python / Node 回归 | 被测试规则、接口、页面状态在当前代码上满足断言 | 真实模型精度、扬声器实际出声、CM5 性能 |
| 当前基线前身的回滚日志 | 回滚完成时的本机回归结果 | 重命名后未经复跑的全部行为、当前板端验收 |
| 历史 Windows 模型/API 测试 | 对应旧代码、模型、输入及开发机环境的结果 | CM5 的延迟、温度、内存或音频表现 |
| 历史 CM5 测试包 | 当时板端发布及硬件环境的结果 | 当前 v1.0.0 已部署或拥有相同结果 |
| 混合运行日志 | 排查具体请求、故障和时间线 | 不经筛选直接计算版本成功率 |

**模型配置不同：** 当前 v1.0.0 默认是 MiniCPM-V 4.7 1B Q4_K_M；历史 CM5 主测试默认是 Qwen3-VL-2B Q4_K_M，并使用不同图像尺寸、线程/绑核配置及后续修复。历史 CM5 数字不能作为当前默认模型的性能承诺。

## 5. 历史结果中需要保留的事实

### 5.1 历史 CM5 语音、外设与回放

- [voice-scenarios.jsonl](../CM5-AI/test-runs/20261102T1450+0800_v130/results/voice-scenarios.jsonl) 有 14 条记录，均标注 synthetic_tts，HTTP 均为 200。其中包含重复的找物品记录，不能称为 14 项独立业务全部验收通过；HTTP 成功也不能证明视觉答案正确。
- [voice-summary.json](../CM5-AI/test-runs/20261102T1450+0800_v130/results/voice-summary.json) 仅保留一条找物品结果，不能当作完整业务汇总。
- [manifest.json](../CM5-AI/test-runs/20261102T1450+0800_v130/manifest.json) 对部分 voice-*.wav 的来源标注为 real_device_microphone，与场景记录及报告的“合成语音”口径冲突。保留原始元数据；本文按场景记录归类为合成驱动，不据此计算真人唤醒率。
- 同一 manifest 的人工确认项 speaker_audible_human、human_wake_word_accuracy、guide_obstacle_scenarios 均为 false。aplay 返回成功不能替代现场听辨，自动结果不能替代真人唤醒及真实障碍验收。
- [Windows 回放摘要](../CM5-AI/test-runs/20261102T1450+0800_v130/replay-out/summary.json) 中 3 帧均为 unavailable/no_seed；[故障注入摘要](../CM5-AI/test-runs/20261102T1450+0800_v130/replay-out-faults/summary.json) 输入 3 帧、处理 2 帧、丢弃 1 帧。它们验证有限素材上的拒绝/丢帧行为，不能证明真实行走方向准确率；回放耗时也不是 CM5 耗时。

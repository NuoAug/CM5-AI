## 性能口径

冷启动和热启动分开；记录请求到首 token、首语义段、TTS 就绪、播放开始、全文完成。首 token 不等于扬声器出声。标明 n、P50/P95、失败数和超时数；小样本不推出可靠 P99。

记录 RSS/PSS 的采集工具和是否对共享页去重；同时记录系统可用内存、温度、欠压、降频和重启。健康 HTTP 200、模型推理成功和语音任务正确应分别记录。

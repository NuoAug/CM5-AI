## 4. ARM64 运行时重建

- 源码：本机 `CM5-AI/runtime/llama.cpp-src`，commit `8ca4060`，版本 0.7.0-dev。
- 设备源码：`~/cm5-ai/runtime/llama.cpp-src-8ca4060`。
- 构建：

```bash
cmake -S llama.cpp-src-8ca4060 -B llama.cpp-8ca4060/build \
  -DCMAKE_BUILD_TYPE=Release -DGGML_NATIVE=ON -DGGML_OPENMP=ON \
  -DLLAMA_CURL=OFF -DLLAMA_BUILD_TESTS=OFF -DLLAMA_BUILD_EXAMPLES=OFF \
  -DLLAMA_BUILD_SERVER=ON
cmake --build llama.cpp-8ca4060/build --target llama-server -j 2
```

- 构建约 8 分 30 秒（2 线程）。
- 二进制：`runtime/llama.cpp/bin/llama-server`，71 KB（共享库），SHA256 `2d7f2bb935790278b283dd8a2c38c2cff021c451cc0aeada760dc45e772f6ff2`。
- `--version`：`0.7.0-dev (build 0, commit unknown)`，GNU 14.2.0 aarch64。
- 无法从无 .git 的源码包生成 commit 信息，因此显示 commit unknown；源码 commit 由本机仓库记录。
- 旧 b11960 运行时已删除，`runtime/llama.cpp -> llama.cpp-8ca4060/build`。

## 6. 功能与性能实测

### 6.1 语音控制（无主控）

用设备 Piper 合成“小冰小冰，开始引导”，POST `/api/voice`：

```text
HTTP 200 wall_ms 2309
text 小兵小冰开始引到
intent guide_start
answer 主控不可用：MAIN_CONTROL_URL 未配置
```

ASR 同音误写经规则归一化后识别为控制意图；主控不可用时明确失败，没有本地补位。耗时含 ASR 冷加载。

### 6.2 纯文字聊天（MiniCPM）

POST `/api/talk`，task=chat：

```text
first_segment_ms 2183
total_ms 2328
answer 我能帮你说说话。你现在感觉怎么样？
segments 1
```

这是热启动、文字路径；不包含取图、OCR 或视觉编码。

### 6.3 单图视觉路径（MiniCPM）

POST `/api/eyes`，task=scene，`samples/scene-corridor.jpg`：

```text
HTTP 200 wall_ms 148827
latency_ms 148800
source vlm
answer 近处是走廊中央的浅色地毯 远是连续的门和顶灯 画面里有障碍物，请注意。
```

视觉路径确实可用，但 148.8 s/帧，远不能实时。该结果再次证明 MiniCPM-V 4.7 只能作质量/兼容基线，不能作为实时视觉默认；M3 必须在主控确认来源与许可后比较候选。

### 6.8 v1.5.0 流式 ASR 部署与实测

release：`v1.5.0-cm5`；v1.4.1 release 已删除。流式模型 `models/asr-streaming/...` 只保留 int8 encoder 157.8 MB、decoder 68.3 MB、tokens，约 226 MB。

CM5 上 `/api/asr/stream/*` 实测（10 秒中英混合测试音频）：

```text
start 200 ms 2597（首次加载）
first_partial 197 ms（加载后首块）
final 200 昨天是 monday today is 零八二 the day after tomorrow 是星期
total_ms 1606（喂完 10s 音频）
load_ms 2581
ready true
```

说明：这是分块喂入的真实增量解码，不是整段反复识别；首次模型加载 2.58 s，之后每 100 ms 块返回临时文本。测试音频为官方 test_wavs，属于合成/公开测试素材，不是真人录音。

`/api/voice` 最终/临时文本区分：

```text
final_text=true  -> intent guide_start，回答“主控不可用：MAIN_CONTROL_URL 未配置”
final_text=false -> intent partial，不触发控制
```

流式 ASR 加载后内存：app RSS 0.47 GB，VLM 空闲 0.64 GB，模型侧合计 1.11 GB，可用 1.90 GB；这是空闲口径，不代表 VLM 视觉推理峰值。

扬声器→麦克风回放“小冰小冰，前面有什么”没有触发唤醒，`last_command_age=null`，没有新建流式会话。原因可能是 AEC 抵消、音量或 KWS 阈值；不能用设备自播代替真人唤醒验收。

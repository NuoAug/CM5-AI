# 文档索引

本目录收录 AI_Eyes 项目（仓库 `CM5-AI` 基线与 `CM5-AI-M` 板端主线）的需求、架构、实施、部署、测试与流程文档。按**文档用途**分类、编号排序；文件名带版本号或记录日期，便于追溯。

## 目录结构

```
docs/
├── main-control-task/       主控下达任务包（权威输入，路径固定）
├── 01-范围与需求/            职责边界、主控适配范围
├── 02-架构与接口/            系统组成、模块职责、设备与模型、接口合同
├── 03-实施记录/              按阶段记录实现与验证（M1–M3）
├── 04-部署与运维/            CM5 部署、回滚、目录恢复
├── 05-测试与验证/            测试日志、报告模板、验收数据、测试用例
├── 06-计划与进度/            工作进度、优化方案与后续计划
└── README.md                本索引
```

1. `main-control-task/01-主控下达语音交互任务.md`：整机任务与职责

## 命名与维护规范

- 目录：`NN-分类名`，序号决定阅读顺序；新增分类需同步更新本索引。
- 文件：`主题-版本.md`（产品/架构/部署类，版本取发布版本）或 `主题-日期.md`（实施/进度/记录类，日期 `YYYYMMDD`）。
- 主控任务包（`main-control-task/`）保留原路径与文件名：`04-GitHub提交与主控审查流程.md` 要求这些文件固定存放、不得自行改写职责与接口语义。
- 历史文档不删除、不原地重写；状态变化时新增记录并在本索引标注。完整证据（日志、JSON、WAV、截图）放 `D:/Desktop/Project/Log-Cache/CM5-AI-M-20261103/`，不随 Git 分发。
- 文档内的相对链接必须可用；批量移动文件后需复查 `README.md`、`AGENTS.md` 与各文档交叉引用。

# 当前问题与风险清单

更新：2026-11-04（Asia/Shanghai）。范围：`CM5-AI`（基线）、`CM5-AI-M`（板端主线）、`CM5-AI/Qwen3.5-0.8B`（候选）、板端 CM5 实机环境与交付流程。

依据：v1.1.28/v1.1.30/v1.1.31 板端验证、Windows 回归（449 项）、`tools/vlm_split.py` 拆测、Log-Cache 阶段报告与历史测试记录。仅列**当前仍存在或尚未验收**的问题；本轮已验证关闭的项单列在文末。

## 优先级总览

| 级别 | 含义 | 主要问题 |
|---|---|---|
| P0 | 阻塞验收或直接导致体验不可用 | 视觉时延、真实唤醒/接续不可靠、真实主控缺失、内存与交换压力、真人验收缺席 |

| P2 | 工程债/流程风险 | 文档版本一致性、测试资产与退场审计、服务不自启、默认参数散落 |

## 六、风险提示（边界与合规）

1. **验收口径**：接口可访问 ≠ 质量/性能通过。报告必须区分真机 HTTP、文件回放、测试替身、真人现场、真实主控五类证据。
2. **行动结论边界**：视觉描述禁止输出障碍/可通行/距离；当前靠提示词+正则拦截，未做模型级保证，需持续回归语料。
3. **AEC 保护模式**：播报期间屏蔽识别是已知限制，不能据此宣称真人插话通过；`AEC_REFERENCE_VERIFIED` 未置位前不得改口径。
4. **价格归属策略**：归属不清时如实说明/澄清，可能与用户"直接给答案"的期望冲突，交互口径需主控/用户确认。

## 建议处理顺序

1. **先解外部阻塞**：与用户/主控确认真人验收窗口、真实主控接入时间、Qwen 资产传输与内存预算、2 小时联合验收安排。
2. **再攻视觉时延**：按拆测结论选一个旋钮（mmproj 量化或更小图像 token 模型）做单参数对照，同时记录内存与首声。
3. **并行语音质量**：真人唤醒/接续/0.9 s 端点 + 提示音验听 + 动态发音 A/B，用同一套记录表。
4. **补真实场景覆盖**：真实遮挡/模糊照片、真实标签 OCR 多样性、方位定位复测。
5. **收尾前**：整机退场审计、部署脚本固化、报告与 CHANGELOG 一致性复查。

## 已实现的功能

- **语音交互。** 接通唤醒、持续收音、流式转写、最终话语路由、生成回答和分段播报。取消覆盖生成、合成与播放，旧轮次的迟到结果和播放器重连后的旧事件有代次过滤。板端生成取消的协议返回仍待修复。AEC 未验证时，播报期间继续采集并保护性屏蔽识别。[M1 语音与取消](../03-实施记录/流式语音与取消-M1-20261103.md)
- **图像追问和对象比较。** 普通追问沿用原帧，重新查看时取新图，取图失败时明确报错。可将 A、B 两个对象分别绑定到图像区域，使用双图比较并保留来源帧。[M2 图片与 OCR](../03-实施记录/图片对象与OCR-M2-20261103.md)
- **OCR 证据。** 保留识别原文、帧号、位置和分数，将文字关联到已确认的对象区域。日期、价格、单位和适用条件分别记录，歧义可追溯到原文。[M2 图片与 OCR](../03-实施记录/图片对象与OCR-M2-20261103.md)
- **主控接口。** 已实现 `interaction.v0.1` 请求适配入口和图像提供接口，正式模式默认由主控供图。引导、通行和距离查询交给主控，未接入时显示不可用。独立实机测试显式使用板端相机。[M0 主控适配](../01-范围与需求/职责范围与主控适配-M0-20261103.md)
- **实机测试与记录。** 网页支持板端相机预览和拍照、音量调节与读回、测试批次、逐题评分、结果 JSON 导出及原图留存。已修复相机红蓝通道顺序和 Piper 被取消后普通回答无声的问题。[树莓派实机测试指南](../../树莓派MiniCPM实机测试指南.md)

## v1.1.28-pi-test 实机阶段结果

2026-11-04，北京时间 10:55 至 11:27。在 4 GB Raspberry Pi CM5 上使用 MiniCPM、板端 IMX708 Wide 相机和 XVF3800 声卡，Windows 通过 SSH 转发发起测试。批次持续 **32 分 9 秒**，记录 44 个用例、50 次交互、384 条资源采样、9 条逐题评价。两张独立实拍证据原图的 SHA-256 已与导出清单核对。带现场内容的原始记录和 WAV 样本保存在指定 Log-Cache。

| 项目 | 本轮实测 | 判定 |
| --- | --- | --- |
| 手写卡 OCR 与证据 | 从板端 1280×720 实拍读取「测试品 A」「￥12.50/盒」「2026-11-04」，三项都对。接口 2.67 秒，应用 OCR 路径 1.90 秒。日期没有写明类型，保留原文。显式选择标签区域后可关联价格行，杯与包的选框和纠正接口也成功。 | 此样本通过。多商品、多价签自动关联待测。 |
| 实拍视觉与追问 | 三次 HTTP 全响应分别为 **155.34、155.98、154.33 秒**，运行器提示评估约 152–154 秒。识别出绿色杯身、粉色盖和黑色包，位置答偏并加入障碍判断。追问沿用相同帧号、答对黑色，同时追加「刚才没看清」。 | 视觉时延未通过，指令遵从和对象定位需修复。 |
| 流式文字与分段 | 30/30 返回完整 SSE 终态，0 次因输出上限截断。Windows 收到首段 P50 **2.69 秒**、P95 **10.02 秒**，完整返回 P50 **3.56 秒**、P95 **14.52 秒**。答错过基础算术和颜色混合，也把用户的饮品偏好说成助手自己的偏好。 | 流式链路可用。时延和回答质量待改。 |
| 真人语音和唤醒 | 真人反复尝试，报告多次无反应、多次「我没听清」、偶尔听到「我在」。日志有 11 条已提交的最终转写，包含「小兵小」等截断、一次「陪我聊聊」和一次误转成「没有聊天」。另有三条合成语音经 ALSA 播放均未触发 final。7 条文件增量回放均生成 final，板端计算 RTF 约 0.12–0.18。 | 真人唤醒与接续未通过。真人尝试总数和整体准确率缺少独立真值。 |
| 音量、发音与取消 | 双声道音量和静音回读成功。应用两次播报观察到 ALSA PCM 运行。按钮取消到观测 PCM 停止约 **14 毫秒**，3 秒内未观察到旧播报复活，随后新播报成功。生成中取消未再输出旧分段，但 SSE 返回内部读取错误。现场听到「无糖豆酱」，模型输出和送入 TTS 的文字均为「无糖豆浆」，板端 eSpeak 中文前端给两词输出相同音素。 | 硬件 PCM 停止通过单次观测。生成取消协议、发音、物理首声和真人插话待修或待测。 |
| 服务稳定性和资源 | 两个服务保持原进程，相机全部采样显示运行。开测发现界面显示监听而 arecord 已退出，重开收音恢复。此前内核有 XVF3800 多次 USB 断连和重新枚举。恢复后另一次采样显示监听与采集关闭，约 5 秒后恢复。最高 **75.2°C**，采样未报降频，最低可用内存 **0.18 GiB**，应用和 VLM 的 RSS 合计峰值 **2.81 GiB**（不含独立 Piper，可能有共享页重叠）。一次采样中约 **2 GiB** 的 zram 交换空间接近用满。 | 服务长测完成，语音掉线与内存压力仍需处理。 |

文字首段以 Windows 发起请求至收到 SSE 分段计时。ALSA 停止以树莓派 PCM 状态计时。扬声器的物理首声和真人插话本轮缺少独立测量，AEC 仍处于未验证的保护模式。

## 待验收事项

1. **相机与视觉。** 修复问句传递、位置回答和低质量画面处理，复测新图、同图追问、多标签关联和 A/B 比较。
2. **真人语音与播报。** 复测真人唤醒、接续、关键实体识别和扬声器实际首声，验听固定提示音与动态发音。验证真实 AEC 参考通道后，再测真人插话的误检、漏检和停止播报延迟。
3. **整机联调与稳定性。** 接入真实主控，验证供图、危险事件、心跳和播放回执闭环，并测量断网冷启动、持续运行、内存和温升。
4. **Qwen 候选。** 扩大同题对照并进行独立人工评分，补齐候选运行资产和目标板验证，再评估是否更换默认模型。

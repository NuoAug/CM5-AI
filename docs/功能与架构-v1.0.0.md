# 功能与架构 v1.0.0

## 服务组成

Python Flask 在 8090 提供网页和 API，llama-server 在 8091 提供 OpenAI 兼容推理接口。网页使用原生 HTML/CSS/JavaScript。VLM、OCR、ASR、KWS 和 TTS 均走本地推理。引导模式及分割推理已移除。

```text
语音输入 → KWS 唤醒 → VAD 整句结束 → Paraformer ASR → 规则意图
  → 控制动作 / OCR / VLM
  → 语义分段 → 输出仲裁 → Piper → 浏览器或 ALSA 播放

设备摄像头 → 预览 / 按需拍照 → OCR / VLM
```

OCR 读字可以避开 VLM；OCR 文字任务失败可回退 VLM，日期任务使用 OCR 字段校验并在不确定时拒猜。

## 页面和设备

| 入口 | 行为 |
|---|---|
| 语音交互 | 看前方、找标识/物品、读字/日期、详细描述、聊天和追问 |
| 调试工具 | VLM 场景、空间关系、图像问答、OCR、TTS 单模块调试 |
| 远程设备控制 | 树莓派摄像头/语音启停、预览、拍照、设备朗读、音量/静音 |
| 主控接口 | 保留调试页面；明确显示未接入 |

远程设备模式下，相机、麦克风和扬声器来自 CM5。

## 语音与输出

唤醒词为“小冰小冰”或“小冰”，服务端维护 15 秒免唤醒窗口。规则意图区分停止播报、关闭摄像头、读字、找物和追问。

输出支持优先级仲裁、有界队列、去重、取消以及同一回答片段追加。常驻 Piper 减少逐段重复加载；浏览器通过 AudioContext 调度，设备端通过同一 aplay 原始 PCM 通道连续播放。

设备语音采用半双工，播报时暂停采集；没有接入带播放参考信号的完整 AEC。语音 API 仍等待整句 ASR 和任务处理；原生流式 ASR 不在本版中。

## 主控接口限制

主控接口未建立真实连接：`GET /api/main-control/status` 返回 configured=false、connected=false；scene/control 返回 HTTP 409。

## API 索引

| 组 | 路由 |
|---|---|
| 状态与指标 | GET /api/status、/api/health、/api/metrics |
| 视觉与文本 | POST /api/eyes、/api/talk（SSE）、/api/vlm、/api/ocr |
| 语音 | POST /api/voice、/api/kws、/api/tts |
| 输出 | GET /api/output/stream；POST /api/output/cancel、/api/trace/event |
| 外设 | GET /api/device/status、/api/camera/preview、/api/camera/still；POST /api/device/voice、/api/device/camera、/api/device/speak；GET/POST /api/device/volume |
| 主控占位 | GET /api/main-control/status、/api/main-control/scene；POST /api/main-control/control |

`/api/status.version` 读取 CM5-AI/VERSION。状态 API 不代表所有模型已完成真实推理验收；部分模型按需加载。

## 源码定位

- app/server.py：API、模型调用、会话、画面时效和任务路由。
- app/intent.py、kws.py、device_voice.py：意图、唤醒和设备语音。
- app/output.py、stream_text.py、tts_worker.py：输出仲裁、文本分段、常驻合成。
- app/device_io.py、device_volume.py：摄像头和 ALSA 控制。
- app/static/device-mode.js：设备测试页面。

本版只统一文档、版本标识和测试证据，不将旧分支的主控适配、流式 ASR 或后续稳定性修复推定为已包含。

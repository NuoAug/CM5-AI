# M3：Qwen 独立候选与第一次对照

日期：2026-11-03。候选代码版本 `1.1.26-candidate`；产品默认仍为 MiniCPM。候选并未通过整机或独立质量验收。本文按“实现 / 验证 / 待办”组织，原有测试数字与限制说明均保留。

## 一、实现

### 1.1 独立工程

已创建 `CM5-AI/Qwen3.5-0.8B/`：独立 app、config、models、runtime、deploy、tools、testsets、samples、logs、data、test-runs、VERSION，以及独立虚拟环境。模型、环境、运行时与原始实验记录保持 Git 忽略，不复制或覆盖 MiniCPM 资产。固定来源和 SHA256 见候选 `config/model-manifest.json`。

原始模型为 Qwen/Qwen3.5-0.8B；实际制品是 Unsloth 固定 revision 的 Q4_K_M 和配套 F16 mmproj，分别记录发布者、许可与转换来源。运行器固定官方 llama.cpp b12066 CPU x64。下载字节摘要、真实加载、文字／单图／双图路径及候选独立启动停止均已在开发机运行。目标板运行器仍需单独构建／验证。

完整交互预检明确未就绪：候选尚缺 ASR、OCR、TTS、KWS 的独立运行资产与许可闭合。VLM-only 预检通过不等于整个语音交互可交付；不得回退读取 MiniCPM 的音频资产来伪装独立部署。

### 1.2 公共代码同步

初始派生来自 e213bce；最终公共模块来源为 `dad8709ae1953532a30e1dd22fadce7693c5ad9`。候选 `config/shared-source.json` 记录每个同步源文件摘要，候选专用配置、路径、身份校验和完整预检保留独立差异。

## 二、验证

### 2.1 第一次相同输入对照

复现：候选目录执行：

```powershell
app/.venv/Scripts/python.exe tools/compare_runners.py --baseline-root ../MiniCPM-V4.7-1B --port 18111 --output test-runs/paired-runner-compare/results.json
```

两模型均使用同一 b12066、CPU、4线程、context2048、parallel1、temperature0.2、top_p0.9、cache_prompt=false、enable_thinking=false。图像固定512边长／JPEG85。四题输入及冻结的多轮历史逐字节摘要相同；每题只运行一次，没有 P95。

| 固定输入 | 输出预算 | MiniCPM 首内容／总耗时 ms | Qwen 首内容／总耗时 ms | Mini／Qwen结束 |
| --- | ---: | ---: | ---: | --- |
| 自然聊天 | 128 | 495／2952 | 422／4359 | stop／length |
| 多轮聊天 | 160 | 869／4287 | 882／6016 | stop／length |
| 详细解释 | 256 | 577／8791 | 434／7736 | stop／length |
| 单图猫场景 | 128 | 3520／6838 | 2020／5408 | stop／stop |

这是运行器首内容时间，不是有效语音首声。token 数在不同分词器之间不等价；相同预算用于暴露各自输出行为，不保证语义长度相同。

单个 Windows 运行器每100ms采样，观察到的 private 峰值：MiniCPM 2,390,216,704 字节，Qwen 1,628,385,280 字节；working set 峰值分别 2,280,632,320／1,385,005,056 字节。两种指标重叠，不能相加；未包括 Python、ASR、TTS、系统和主控，也不能换算成目标板整机 RAM。每次只加载一个模型，结束时核实自有进程退出；未控制 OS 文件缓存，顺序固定 MiniCPM→Qwen。

### 2.2 候选回归

最终候选全套355项：351通过，4项因KWS资产未安装明确跳过；另有网页Node回归通过、PowerShell脚本语法检查通过。14项运行器边界及10项候选隔离／预检边界已包括在该总数内，未另行相加。无跨工程环境路径、外部VLM地址或HTTP重定向回退；实际生成前验证本机运行器的模型身份。完整交互需要完整资产与同版本／同摘要的真实运行回执，空文件不能伪装ready。

这些回归不提供真人、目标板或独立质量通过证据。

### 2.3 最终模型 API 烟测

使用候选自己的PowerShell启动器及最终ModelRunner，每次生成先核运行器身份并拒绝重定向：32tokens上限下，文字690ms（stop），猫图1901ms（回答2，stop）。内置Windows PowerShell5.1实际启动，专属stop退出0，PID记录移除，18120／18121端口均释放。此为开发机运行器接口烟测，未运行完整语音服务，不评价首声／真人质量。

脚本实测补齐UTF8 BOM兼容5.1；首次验证脚本因后代继承PIPE句柄等待超时，之后将输出定向本地日志文件后完成。本报告保留该次验证失败说明，不将测试脚本调整描述为模型质量通过。

## 三、待办

- 质量判断：Qwen 三条文字回答达到长度上限；有模板化长答和事实措辞问题。MiniCPM 多轮仍出现用户／助手人称混淆。四题没有独立人工质量评分，不足以选择模型，更不能认为 Qwen 中文质量已通过。暂不替换默认模型。
- 失败审查工具 `tools/export_failure_review.py` 保留输入摘要、输出、版本证据、finish_reason及人工复核字段；仅客观自动标记 length，主观质量、修复建议、许可、训练／独立测试划分待人工审核。当原实验没有记录版本时填 null，不能用后来源码版本冒充实测版本。
- 先用扩大且独立的真实测试集区分预算／提示／角色组织和模型失败，按完整语义比较。若仍有质量失败，再增加一档较高精度对照区分量化退化；然后才决定是否有必要做有限微调。当前未训练，没有把四题输出自动变成训练数据。
- MeloTTS、目标板线程／上下文／图像档位对照、30分钟稳定性和2小时联合热／电池测试仍未完成。

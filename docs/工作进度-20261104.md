## 使用的模型

| 模块 | 模型与运行方式 | 用途 |
| --- | --- | --- |
| 图文理解和聊天 | **MiniCPM-V 4.7 1B**，Q4_K_M GGUF + F16 视觉投影。树莓派测试版使用 ARM64 llama.cpp b12066，CPU 3 线程、上下文 2048。 | 场景描述、找物、看图问答和文字聊天。 |
| 图文候选 | **Qwen3.5-0.8B**，Q4_K_M GGUF + F16 视觉投影，Windows x64 llama.cpp b12066。 | 评估同一输入下的耗时、内存和回答表现。 |
| 语音识别（ASR） | **sherpa-onnx 流式中英双语 Paraformer INT8**，树莓派单线程运行。另保留离线 Paraformer small INT8 作为整句识别基线。 | 增量转写和最终话语识别，按最终结果路由指令。 |
| 关键词唤醒（KWS） | **sherpa-onnx Zipformer WeNetSpeech 3.3M**。 | 检测“小冰小冰 / 小冰”。 |
| 文字识别（OCR） | **PP-OCRv6 small ONNX**，由 RapidOCR 运行。 | 识别标签原文，辅助提取日期、价格、单位和适用条件。 |
| 语音合成（TTS） | **Piper zh_CN-huayan-medium**，常驻进程合成，树莓派通过 ALSA 播放。 | 按语义分段播报回答，支持停止播报。音色分发许可待核实。 |

## 已实现的功能

- **语音交互。** 接通唤醒、持续收音、流式转写、最终话语路由、生成回答和分段播报。取消覆盖生成、合成与播放，旧轮次的迟到结果和播放器重连后的旧事件会被丢弃。AEC 未验证时，播报期间继续采集并保护性屏蔽识别。[M1 语音与取消](M1-流式语音与取消-20261103.md)
- **图像追问和对象比较。** 普通追问沿用原帧，重新查看时取新图，取图失败时明确报错。可将 A、B 两个对象分别绑定到图像区域，使用双图比较并保留来源帧。[M2 图片与 OCR](M2-图片对象与OCR-20261103.md)
- **OCR 证据。** 保留识别原文、帧号、位置和分数，将文字关联到已确认的对象区域。日期、价格、单位和适用条件分别记录，歧义可追溯到原文。[M2 图片与 OCR](M2-图片对象与OCR-20261103.md)
- **主控接口。** 已实现 `interaction.v0.1` 请求适配入口和图像提供接口，正式模式默认由主控供图。引导、通行和距离查询交给主控，未接入时显示不可用。独立实机测试显式使用板端相机。[M0 主控适配](M0-范围与主控适配-20261103.md)
- **实机测试与记录。** 网页支持板端相机预览和拍照、音量调节与读回、测试批次、逐题评分、结果 JSON 导出及原图留存。已修复相机红蓝通道顺序和 Piper 被取消后普通回答无声的问题。[树莓派实机测试指南](../树莓派MiniCPM实机测试指南.md)

| 验证范围 | 结果 |
| --- | --- |
| 树莓派部署和外设 | 已验证 Windows 访问板端服务、相机抓图、麦克风采集和 ASR 模型加载、ALSA 播放的软件链路及音量读回与恢复。实物颜色、真人识别质量和扬声器实际首声仍待测。[实机测试台](../CM5-AI-M/README.md) |

## 待验收事项

1. **相机与视觉。** 在稳定照明下确认画面和实物颜色，复测新图、同图追问、标签 OCR 和 A/B 比较，记录超时、误识别和低质量画面的回答。
2. **真人语音与播报。** 验收唤醒、关键实体识别和扬声器实际首声。验证真实 AEC 参考通道后，再测真人插话的误检、漏检和停止播报延迟。
3. **整机联调与稳定性。** 接入真实主控，验证供图、危险事件、心跳和播放回执闭环，并测量断网冷启动、持续运行、内存和温升。
4. **Qwen 候选。** 扩大同题对照并进行独立人工评分，补齐候选运行资产和目标板验证，再评估是否更换默认模型。

这些是既有设备配置及已部署系统的历史记录，不证明板端此刻运行 v1.0.0 或已加载下述默认模型。远程访问命令见[根说明文档](../README.md#树莓派配置)，具体部署区分见[部署与运维](../04-部署与运维/CM5部署与运维-v1.0.0.md)。

仓库 deploy/ 是 /opt/cm5-ai + 系统用户 cm5 的通用安装模板，与已有用户部署路径不同；本轮未执行该模板或迁移设备目录。

## 当前默认模型

以下路径均相对 CM5-AI/MiniCPM-V4.7-1B/；仅描述本版默认执行路径，不把本地候选目录认作已启用。

| 模块 | 模型与路径 | 推理方式 |
|---|---|---|
| VLM | models/vlm/MiniCPM-V 4.7 1B/MiniCPM-V-4_7-1B-Q4_K_M.gguf + mmproj-model-f16.gguf | llama.cpp，CPU，Q4_K_M + f16 投影 |
| OCR | models/ocr/pp-ocrv6-small/PP-OCRv6_det_small.onnx、PP-OCRv6_rec_small.onnx、ch_ppocr_mobile_v2.0_cls_mobile.onnx | RapidOCR + ONNX Runtime |
| ASR | models/asr/sherpa-onnx-paraformer-zh-small-2024-03-09/model.int8.onnx，另需 tokens.txt | sherpa-onnx OfflineRecognizer，整句识别，16 kHz |
| KWS | models/kws/sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01/ | KWS_INT8=0；默认 epoch-12 普通 ONNX encoder/decoder/joiner，另需 tokens.txt |
| TTS | models/tts/piper-zh_CN-huayan-medium/zh_CN-huayan-medium.onnx，配套 .onnx.json | Piper 常驻 worker，22,050 Hz 单声道 |

KWS 关键词来自 app/config/keywords.txt，当前为“小冰小冰 / 小冰”。目录内 epoch-99、int8 或其他候选不等于默认加载；模型选择依据 kws.py 的文件名排序及 KWS_INT8。

引导模式已移除，不再加载分割模型。models/asr-streaming/、tts-candidates/ 和其他 VLM 候选不属于当前默认链路。历史设备报告中的 Qwen3-VL-2B 不是本版默认模型。

## 参数口径

删除引导模式时仅清理其仓库模板参数，设备上的环境文件保持原样。代码无覆盖默认、部署模板和设备现有环境是三个不同来源。

| 参数 | 代码无环境覆盖 | CM5 部署模板 |
|---|---:|---:|
| MEM_BUDGET_GB | 3.6 | 3.2 |
| ASR_THREADS | 4 | 1 |
| OCR_INTRA_THREADS / OCR_INTER_THREADS | 4 / 1 | 2 / 1 |
| KWS_THREADS | 1 | 1 |
| VLM_THREADS | Windows：≤4核为4，否则8 | 4 |
| VLM_CTX | 1024 | 1024 |

共同设置：Web 8090、VLM 8091；CPU -ngl 0、parallel 1；ASR 空闲 180 秒释放；Piper persistent、默认不空闲释放；VLM 图像最大边 512；唤醒窗口 15 秒。模板 ALSA_INPUT/OUTPUT=plughw:0,0 是示例，不能覆盖设备 Array 配置。
